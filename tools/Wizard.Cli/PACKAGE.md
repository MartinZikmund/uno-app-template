# mzuno-app

Create production-shaped [Uno Platform](https://platform.uno/) apps and keep them up to date.

```bash
dotnet tool install -g MZikmund.UnoApp.Cli

mzuno-app new            # guided, in the terminal
mzuno-app wizard         # visual, in your browser
mzuno-app features       # what you can pick
mzuno-app upgrade        # what an existing app can pick up from newer template versions
```

Documentation: <https://github.com/MartinZikmund/uno-app-template>
